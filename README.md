# NUMBERS BY KAYLOV — website

Готовый адаптивный сайт на обычных HTML, CSS и JavaScript. Сборка и установка не нужны.

## Что внутри
- `index.html` — весь текст, прайс и структура страницы.
- `style.css` — дизайн, адаптация под телефон, плавные эффекты.
- `script.js` — мобильное меню, вкладки категорий и интерактивность.
- `assets/hero-portrait.jpeg` — фото для первого экрана.

## Перед публикацией
1. Открой `index.html`.
2. Найди внизу раздел `CONTACTS`.
3. Замени `href="#"` у OWNER, ANON и REVIEWS на свои реальные ссылки.
4. Проверь актуальность цен и гарантийных условий.

## Как выложить через GitHub Pages
1. Создай аккаунт на https://github.com/ (если его ещё нет).
2. Нажми `+` → `New repository`.
3. Назови репозиторий `numbers-by-kaylov`.
4. Выбери `Public`, затем `Create repository`.
5. На странице репозитория нажми `Add file` → `Upload files`.
6. Загрузи **содержимое этой папки**: `index.html`, `style.css`, `script.js`, `README.md` и папку `assets` с изображением. Не загружай ZIP вместо отдельных файлов.
7. Нажми `Commit changes`.
8. Открой `Settings` → `Pages`.
9. В разделе `Build and deployment` выбери `Deploy from a branch`.
10. Branch: `main`; folder: `/ (root)` → `Save`.
11. Подожди минуту-две. В `Settings` → `Pages` появится ссылка примерно такого вида:
   `https://ТВОЙ-НИК.github.io/numbers-by-kaylov/`

Если сайт не открылся сразу, обнови страницу Pages через минуту.

## Как обновлять сайт
Измени файл в репозитории через значок карандаша или загрузи новую версию через `Add file` → `Upload files`. После `Commit changes` GitHub Pages обновит сайт автоматически.

## Важно
- Для Google Fonts нужно подключение к интернету; при недоступности сайт использует запасные шрифты.
- Ссылки на контакты пока заглушки.
- Это статический сайт: заказы и платежи автоматически не обрабатываются. Для заказов пользователь пишет тебе по ссылке.
